# 读者内容规则

这篇文档说明呈现在网站上的内容要满足哪些要求：怎么排先后、怎么处理某群当天没稿、怎么标重点下划线、怎么附 AI 锐评与原始讨论，以及隐私红线划在哪里。能靠代码检查的规则已经写进了构建与入库脚本；剩下的由编辑在审稿时把关。

前期的微信消息采集、模型 prompt 和审稿操作流程在 [bot-workflow](https://github.com/Agent-Hub-Community/bot-workflow) 仓库。

## 内容定位

日报的读者主要是群里的 Agent 研究者和工程师。大家多半是从微信群里点开链接，在手机上花几分钟扫一眼今天别的群聊出了什么干货。

- 打开首页直接就是最新一期的正文，每个群一版，外部资讯单占一版。
- 写讨论的来龙去脉、具体数据和分歧点，不记“甲说了 A、乙说了 B”的流水账；哪条聊得深就排在前面，条数多少全看当天有几件值得说的事。
- 不做花哨的营销落地页，也不给群友打“发言质量分”。

## 某群当天没稿怎么处理

- 如果某个群当天本地没记录、或者聊的都是闲话没法成稿，该版的 `stories` 就留空数组 `[]`，页面上如实显示暂无稿件。
- 绝不拿别的群或前几天的新闻过来塞版面。
- 后加入的群（比如五群）在它的 `pageFrom` 日期之前没有读者版面，往期页面不会替它补空壳。

## 重点下划线（`emphasis`）

每条故事的 `emphasis` 数组存着要在正文里加浅色底线和适度加粗的原文短句，方便读者扫读时一眼抓到核心结论或分歧。模型写稿时会先挑一版，编辑审稿时再逐条核对或替换。

代码自动检查三条硬规则（[`lib/emphasis.mjs`](../lib/emphasis.mjs)）：

| 检查项 | 要求 |
|---|---|
| 逐字唯一匹配 | 每个片段能在所属 `text` 里原封不动找到，且只出现一次 |
| 不重叠、不跨段 | 片段之间不重叠，单条片段不包含换行符 |
| 长度比例 | 单条至少 2 个字符、首尾无空格；所有片段加起来不超过 `text` 总长度的 30% |

编辑审稿时看两条：

- 短文标 1 到 2 处；长文按自然段看，有实质判断、机制解释或反驳分歧的段落每段标 1 处，纯背景过渡段可以不标。
- 标完整的判断句（如果原句带“有人猜测”这类限定，把限定一起圈进来），别只标孤零零的模型名，也别把未经核实的传言标成铁板钉钉的结论。

## AI 锐评

每条故事正文下面跟一段独立的 `aiComment`（周报里叫 `review`），页面上标为“AI 锐评”。

- 它是模型站在懂行群友角度接的一句调侃或点评，不代表群内共识，也不是事实证据。
- 长度限制在单行 6 到 90 个字符，不能带 `<` 或 `>`。
- 锐评跟正文版本绑在一起：改了正文之后，要先确认锐评还对得上、没写出和正文打架的话。

## 原始讨论节选

挂了 `discussion` 字段的话题，正文下方会出现“原始讨论 N 条 · M 人”按钮，点开能看当时的对话过程。

- 里面只留单条话题内部的匿名编号（页面展示成“群友 1”“群友 2”）、时间和原话，不同话题里的“群友 1”不是同一个人。
- 讨论节选保留围绕该话题的完整来回（包括猜测、追问与玩梗），复读刷屏或接龙只留一两条代表；只隐藏发言人身份，不改写原始消息正文（包括正文里的 `@昵称`）。
- 群友发的图片在讨论浮窗里统一显示为 `[图片]`，不会把视觉模型写的图片描述塞进气泡冒充群友发言。
- 外部资讯版没有原始讨论入口；给 Agent 读取的 Markdown 和检索 API 也不导出讨论原话。

## 隐私与头像

网站上公开的所有文字、卡片、榜单和图片都守住下面几条线：

- 不写群友真名、微信昵称、微信号、手机号、邮箱。正文一律用“群友”“分享者”“另一位使用者”代称。
- 不写能定位到个人的背景信息（学校、地区、职位、工作履历），不写群友所在的公司名或透露的内部业务；群友评价某家公司或团队时，隐去公司名。
- 可以保留公开论文、GitHub 仓库和产品链接，但别把公开作者和群内发言人连起来（哪怕作者本人在群里发自己的项目，也只写“有群友分享了某项目”）。
- 活跃榜只公布各群与社区前三名的名次和头像，不公布具体发言条数和计分细则。
- 活跃榜、周榜和资料库里的成员头像虽然不带名字，但熟人一眼能认出来，所以不算匿名数据。每张新头像都要人工看过、排除未成年人照片和“暂时无法查看”占位灰图后才能入库；拿不准的直接置空，页面会显示默认占位图标。
- 招聘、活动与征稿机会不写发帖人，也不允许带个人邮箱、手机号、微信号或“加微／私聊”字样。

如果有群友希望撤下涉及自己的某段发言或头像，按 [`CONTENT-NOTICE.md`](../CONTENT-NOTICE.md) 的说明提 issue 即可处理。
