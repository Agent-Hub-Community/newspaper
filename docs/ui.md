# 界面规则

本文记录网站各页面的界面约定。改动界面前请先读对应的一节，改完后按 [测试](testing.md) 运行浏览器测试，并附上桌面和手机宽度的截图。

## 通用原则

- 首屏就是可读的正文。一群一版，用顶部的群按钮切换。正文的滑动只用于阅读。
- 日报、周报、资料库、黑话和活跃榜共用同一套刊头和导航。
- 保留键盘操作、可见焦点和减少动效设置。标签和状态不只用颜色表达。
- 手机默认字号可读。不裁切文本来凑一屏；高度小或放大字号时，页面自然滚动。
- 模拟器和无头浏览器的结果不等于微信内置浏览器的真机验收。

## 刊头与换期

- 刊头左边是“AgentHub | 栏目名”，右边是日期和星期（周报是期次，资料库是数量），手机上也在同一行。
- [`site/daily.css`](../site/daily.css) 末尾的刊头规则照搬 [`site/weekly.css`](../site/weekly.css) 在各宽度下的数值。
- 换期只有一个入口：点刊头日期，或点桌面的“往期目录”。
- 往期列表按月分组，每期一行：日期和星期、当前群那一期的报头，以及当天有稿的群。当天当前群无稿时，显示第一个有稿群的报头，并注明本群无稿。列表顶部是上一期和下一期。
- 只有节日皮肤生效时，日报刊头上方才显示皮肤眉题。

## 日报版面

每期包含当天各群的版面和同日的外部资讯版。版面列表由 [`lib/groups.mjs`](../lib/groups.mjs) 的 `pageGroups(date)` 决定。

- 群稿是等宽双列，宽度 700px 及以下改为单列。标题在正文上方，长讨论保留自然段。外部资讯和周报使用各自的布局。
- 每条的尾部只有一行：原始讨论入口和赞踩。AI 锐评不用色条，资料链接每条一行。
- 外部资讯版的报头概括当期主要动态，日期单独显示。外部资讯版不显示群活跃榜，也没有原始讨论入口。
- [`site/daily.css`](../site/daily.css) 的 `[data-page-count="6"]` 支持手机上的六版导航。新增版面后，请检查 320px 和 390px 宽度。

缺稿的处理：

- 切换日期时，优先保留当前版面。当前版面缺稿时，换到当天第一个有稿的版面。
- 整期无稿的日期在目录里置灰，翻期时跳过。
- 缺稿版面的按钮置灰，标“暂无稿件”，键盘切群时跳过它。
- 直接打开缺稿版面的链接时，页面换到当天有稿的版面并更新地址。整天无稿的历史链接保留原日期，如实显示空状态。

## 原始讨论面板

编辑核对原始消息后，才给话题附加 `discussion` 字段。有这个字段的话题，在正文下显示“原始讨论 N 条 · M 人”按钮。周报使用同一个面板，由 [`site/discussion-panel.js`](../site/discussion-panel.js) 实现。

布局：

| 宽度 | 布局 |
|---|---|
| 900px 以上 | 居中的跨页，最宽 1180px。左栏约占 37%（340–440px）是编辑导读，右栏是聊天记录 |
| 701–899px | 从右侧滑出，宽 640px，导读折叠在聊天上方 |
| 700px 及以下 | 全屏，导读折叠在聊天上方 |

- 左栏导读写版面、话题序号、标题、带重点的正文、AI 锐评和资料链接，底部切换话题。页面通过 `configure({ topic })` 传入导读内容。
- 右栏顶部写条数、人数和时间段。聊天记录居中，最宽 680px，末尾标出“以上是全部 N 条消息”。
- 正文位置不动。关闭按钮、Esc、遮罩和系统返回键都关闭面板，并把焦点还给按钮。
- 打开时，地址追加 `#discussion-N`，可以分享和刷新（`file://` 预览只记历史状态）。切换话题用 `replaceState`，所以返回一次就回到正文。面板记住每个话题的阅读位置。

聊天记录：

- 同一人的连续消息共用发言头，每条是一个气泡，底色是发言人颜色的浅色。匿名编号配固定颜色。手机正文用 16px 字号。
- 周报跨天时，在新一天开始处显示日期分隔线。发言头只显示时刻，完整日期写在读屏标签里。
- 引用压成“↩ 群友 N：引文”，最多两行。能唯一匹配节选中较早的原消息时，点击定位并短暂高亮，离开视野后底部出现“回到引用处”。确定不了原消息时，点击展开完整引文。
- “[文件]”显示文件名和大小。“[表情]”“[媒体引用未解析]”显示为浅色标签，自定义表情包不展示。
- “[旺柴]”“[捂脸]”等微信内置表情码显示为最接近的 Unicode 表情，由系统字体绘制。悬停显示原代码，读屏读中文名。映射表以外的代码保持浅色文字。

## 网址和资料卡片

- 微信导出的“[链接] 标题 / 来源 / 摘要 / URL”显示为整卡可点的卡片。
- 整条消息只有网址时，每个网址显示为同样的卡片。来源写站点名，子域名退到主域名（如 zhuanlan.zhihu.com 写“知乎”）；标题写 arXiv 编号、GitHub 仓库或网址路径。
- 夹在正文里的网址留在原位置，显示为“域名 + 路径”的短链接，过长时截断。完整地址在链接和悬停提示里。
- 带账号密码，或带 token、key 等查询参数的网址保持纯文本。
- 引文是按钮，不能嵌链接。引文里的网址只显示文字。
- 导读、日报文章页和周报文章页的相关资料是统一的卡片：类型图标、名称、域名和外链箭头。图标由 `AgentHubDiscussion.resourceKind()` 决定：github.com 显示代码，arxiv.org 显示论文，其余按 `kind` 归类。资料栏宽于 686px 时，卡片排成两列。

## 活跃榜

活跃榜是独立栏目（[`site/ranking.js`](../site/ranking.js)），统计的是参与次数，不是内容质量。

- 标题旁三个按钮切换周榜、月榜和总榜。面板列出全社区和各群的前三名：桌面按群数等宽并排，1040px 以下每群一行。
- 某个群的记录晚于榜单起点时，群名下写“M 月 D 日起”。截止日期只在刊头显示。
- 从某群日报点进活跃榜时，地址带上该群（`rank/<周期>/<群>/`），只用于点回日报时回到该群。
- 手机上，从正文后的入口或日期目录进入活跃榜。日报页右上角另有本群日榜，只显示本群前三名的名次和头像。
- 周榜按北京时间自然周，月榜按自然月，总榜只代表本地留存期。

## 保存本版图片

“保存图片”把当前这一版（刊头、日期、群、标题、全部条目和 AI 锐评）渲染成一张 PNG 长图。图片在浏览器本地生成，不上传。

- 生成库是固定版本的 modern-screenshot，构建时复制为 `screenshot.js`，第一次保存时才加载。[`site/share-image.js`](../site/share-image.js) 负责调用和预览弹窗。
- 页面先复制到屏幕外，再隐藏栏目切换、翻期、赞踩和按钮本身，所以读者正在看的页面不重排。页脚换成本版链接，图片被转发后仍能找到原页。
- 头像取自页面已加载的图片像素，不另外请求网络。用 `file://` 打开时，浏览器不允许读取图片像素，图里的头像会留空。
- 桌面浏览器直接下载，文件名形如 `AgentHub日报-2026-09-23-一群.png`。手机显示全屏预览；支持文件分享的触屏浏览器另外显示“分享图片”。
- 图片按 2 倍像素密度输出。总像素超过 1600 万或单边超过 16384px 时，自动降低倍率，避开 iOS Safari 的画布上限。
- 刊头品牌使用 `translate="no"`，避免翻译扩展重复品牌。系统分享面板和第三方翻译扩展要在真机上复核。

## 皮肤与明暗

- 页面默认跟随系统的浅色或深色模式。顶部的明暗按钮依次切换跟随系统、浅色和深色，选择保存在本机。
- 节日皮肤是仓库内的插件。每个皮肤都要提供亮、暗两套样式，缺一套时构建失败。活动排期到期后自动恢复常规版。
- 插件约定和排期见 [`site/skins/README.md`](../site/skins/README.md)。
- 本地构建后，用 `?skin=mid-autumn` 预览中秋皮肤，用 `?skin=default` 对照常规版。
