# 界面规则

这篇文档记录网站各个页面的排版与交互约定。改样式或前端脚本前请先看一下对应章节，改完后按[测试说明](testing.md)跑一遍浏览器测试，并在 PR 里贴上桌面与手机宽度截图。

## 整体原则

- 打开页面第一屏直接看正文，每个群一版，点顶部的群页签切换。
- 日报、周报、资料库、黑话、活跃榜和全站搜索共用同一套顶部刊头和栏目导航。
- 保证键盘可操作、焦点边框清晰、尊重系统的减少动效设置（`prefers-reduced-motion`），状态提示不单靠颜色区分。
- 手机端字号舒适，不靠硬截断文字去凑单屏高度。

## 刊头与翻期

- 刊头左侧固定是“AgentHub | 栏目名”，右侧是当前日期和星期（周报显示期次，资料库显示收录条数），手机上也排在同一行。
- 翻看往期只有一个入口：点刊头右侧的日期，或者点桌面端右上角的“往期目录”。
- 往期弹层按月分组，每期一行，列出日期、星期、当前所选群那一期的报头，以及当天有稿的群标签；如果所选群那天没稿，会借用当天第一个有稿群的报头并注明本群无稿。

## 日报版面与缺稿回退

每天的日报包含当天各群版面（由 [`lib/groups.mjs`](../lib/groups.mjs) 的 `pageGroups(date)` 决定）和最后一版“外部资讯”。

- 群稿在桌面与平板宽屏（`> 700px`）下排成等宽双列，`≤ 700px` 下切成单列，标题都在正文上方。外部资讯和周报有各自的排版。
- 每条故事底部只有一行：左边是“原始讨论 N 条 · M 人”按钮，右边是赞踩按钮。
- 外部资讯版不展示群活跃榜，也没有原始讨论按钮。
- [`site/daily.css`](../site/daily.css) 的 `[data-page-count="6"]` 专门适配了五群加外部资讯共六个页签在手机窄屏（320px、390px）下的排列。

遇到某版缺稿时的行为：

- 切换日期时尽量留在当前选中的群；如果该群当天没稿，自动切到当天第一个有稿的版面。
- 当天没稿的群页签置灰、标“暂无稿件”，键盘左右切群时自动跳过。
- 直接点开某个缺稿版面的深链时，前端会自动跳到当天有稿的版面并更新地址栏；只有整天所有版面都没稿的历史链接才留在原页显示空状态。

## 原始讨论浮窗

带 `discussion` 字段的话题，点开“原始讨论 N 条 · M 人”会弹出当时的对话记录（日报和周报共用 [`site/discussion-panel.js`](../site/discussion-panel.js)）。

| 视口宽度 | 展示形态 |
|---|---|
| `≥ 900px` | 居中双栏弹窗（最宽 1180px）：左栏约占 37%，放编辑导读（标题、带重点的正文、AI 锐评与资料卡）；右栏放聊天记录 |
| `701–899px` | 从右侧滑出 640px 宽的抽屉，导读折叠在聊天上方 |
| `≤ 700px` | 全屏打开，导读折叠在聊天上方 |

- 点关闭按钮、按 `Esc`、点背景遮罩或按手机系统返回键都能关掉浮窗，并把焦点还给原来的按钮。
- 打开浮窗时地址栏会加上 `#discussion-N`，支持直接复制链接分享或刷新；在浮窗里切换上一条／下一条话题用 `replaceState`，点一次返回就能退回正文。
- 聊天记录里，同一位“群友 N”连续发的多条消息共用一个发言头，每条消息一个浅色气泡；跨天讨论在新一天开头插一条日期分隔线。
- 引用回复压成最多两行的“↩ 群友 N：引文”；如果引用的原消息也在当前节选里，点一下会直接滚过去并高亮，滚远后底部会出现“回到引用处”小按钮。
- 微信自带的 `[旺柴]`、`[捂脸]` 等表情码会转成对应的 Unicode emoji 显示，悬停能看原词。

## 链接与资料卡片

- 微信导出的 `[链接] 标题 / 来源 / 摘要 / URL` 或单条纯网址消息，在讨论浮窗里会画成整张可点的链接卡片；夹在句子中间的普通网址则简化成“域名 + 短路径”的内联链接。
- 带账号密码，或者带 `token`、`key` 等敏感参数的网址一律退回纯文本，不渲染成可点链接。
- 文章下方的相关资料统一画成带图标的卡片（`github.com` 显示代码图标，`arxiv.org` 显示论文图标，其余按 `kind` 区分），容器宽于 686px 时排成两列。

## 活跃榜与保存长图

- 活跃榜页面（[`site/ranking.js`](../site/ranking.js)）顶部三个按钮切换周榜、月榜和总榜，下方并排展示全社区和各群的前三名头像（`≤ 1040px` 时改成每群一行）。日报群版面的右上角还会顺带挂一个本群当日的前三名小榜。
- 点“保存图片”（[`site/share-image.js`](../site/share-image.js)）会按需加载 `screenshot.js`（modern-screenshot），在屏幕外克隆当前版面、隐藏导航和赞踩按钮、把页脚换成当前版面的网址，生成一张 2 倍分辨率的 PNG 长图（碰到超长版面会自动降倍率，避开 iOS Safari 的画布上限）。桌面端直接触发下载，手机端弹出全屏预览并调用系统分享面板。

## 明暗模式与节日皮肤

- 全站默认跟随系统的浅色／深色模式，点右上角的图标可以在“跟随系统 / 浅色 / 深色”之间切换，偏好存在本地 `localStorage`。
- 节日皮肤放在 [`site/skins/`](../site/skins/README.md) 下，按排期自动生效，也可以在地址栏加 `?skin=mid-autumn`、`?skin=national-day` 或 `?skin=default` 手动预览。
