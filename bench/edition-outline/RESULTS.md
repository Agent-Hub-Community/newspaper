# 单期目录阅读结果

2026-10-17，在冻结的 2026-10-16 日报上比较。47 个话题的标题、栏目与正文版本保持一致。
结果来自本地公开构建和 HTTP handler；不包含网络延迟、压缩或模型推理成本。

| 阅读任务 | 旧路径 | 新路径 |
|---|---|---|
| 找最新一期并浏览全部标题 | 4 次请求，75,189 字节 | 1 次请求，15,441 字节 |
| 从目录选 MAI-Gym 和 OpenGCUA，读两篇正文 | 整期下载可用：2 次请求，74,244 字节 | 3 次请求，18,423 字节 |
| 只浏览最新日报一群 | 未独立冻结旧路径 | 1 次请求，2,670 字节 |
| 浏览最新周报目录 | 未独立冻结旧路径 | 1 次请求，29,356 字节 |

全部标题目录的响应量减少 79.5%，没有删减话题。
两篇正文的路径多了一次请求，返回量减少 75.2%，正文保留来源和网页引用。
因此更少的请求不是唯一目标，目录选题后再读正文也是成功路径。

验收包括全部话题覆盖、按组继续、周报隔离、缺刊后发现最新一期，以及选中正文的证据检查。
合并主分支后，227 项单元测试和公开构建检查通过；浏览器端与 API 的查询结果一致性检查、Worker 打包检查也通过。
浏览目录不再创建 BM25 索引；首次实际查询才创建并复用索引。

目录仍使用整个 catalog 的服务端缓存，冷缓存时仍需取回全目录。
这里没有证明冷启动延迟降低。周报标题更多，目录也更大，可以用 group 筛选。
只含“动向观察”的栏目会显示趋势数和整组读取入口，不假装已有可独立读取的话题。
