# 单期目录阅读基准

本轮针对“先浏览最新一期，再选择话题阅读全文”。多轮读取是预期路径，不要求首轮得到全部正文。

2026-10-17 冻结发布版本 `e7fa92b`（开源前的内部仓库提交），使用 2026-10-16 的 47 个话题。
`baseline.json` 保存期刊清单、话题 ID/标题/内容版本及旧接口的响应字节数。
`--freeze` 拒绝覆盖文件。后续语料变化应另建基准，不能覆盖本轮基线。

固定验收条件：

- 单次目录请求返回全部 47 个话题标题，按真实栏目分组，保留每个话题的读取链接。
- 目录不含话题正文、AI 评论或每个话题的长摘要；目录正文不超过 20,000 字节。
- 从目录选择 MAI-Gym、OpenGCUA，再读两篇正文，合计不超过 3 次请求和 24,000 字节。
- 标题目录与原语料相符，正文包含原始证据与引用；分组、周报和缺刊恢复分别检查。

旧路径的“浏览标题”需要 1 次期刊发现和 3 次话题分页，共 75,189 字节。
直接读整期需 2 次请求、74,244 字节。字节数为 UTF-8 响应正文，不含请求、HTTP 头或压缩。
因此减少请求数与减少返回量分开报告。

在仓库根目录运行公开构建，再执行 `node bench/edition-outline/run.mjs`。
运行器只调用本地 handler 和构建文件，禁止网络访问，使用模拟统计数据库。
这些是固定阅读路径与证据检查，不是语言模型独立完成任务的成功率；不测线上延迟。
