# 公开 Agent API 第一轮验证

2026-10-17，本地候选已验证，尚未部署。固定指标与结果见 [comparison.md](comparison.md)。
候选实现提交为 `de373dc`；报告中的 `source_sha` 指冻结的基线提交 `4f6160e`。两个 SHA 都属于开源前的内部仓库历史。
本轮没有新增模型、向量数据库或外部检索服务。

## 实际改动

- 网页和 API 共用检索字段与词表，来源标签、URL 也可检索。
- 新增内容搜索、精确条目读取和期刊发现接口。结果提供引用、单话题读取地址及内容版本。
- 资料关联同时包含日报和周报。群与日期条件匹配同一次分享。
- 单话题文件只导出已发布摘要、AI 评论、来源及时间线，不导出聊天逐句原文。
- 两个查询接口均提供带版本的 `next_url`，版本不符时返回 HTTP 409。

## 验证结果

214 项单元测试、公开构建检查、桌面与手机网页/API 对照、Worker 打包预检均通过。
构建检查逐项验证 889 个条目的读取文件。独立审查核对全部资料关联，断链为 0。
浏览器对照用 6 个查询验证结果数量和排序，并阻断所有外部网络请求。
资料库和全站搜索的完整浏览器回归也已通过，包括筛选、排序及同义词查询。
完整回归发现并修复了“基座模型”查询排除仅含“基模”的条目问题。
实体检查现在接受词表中登记的同义写法，同时保留未知实体的拒绝规则。

独立评审另选 6 个读者问题，按预先给定的请求数与字节预算调用本地接口。
这不是受控的语言模型 agent 成功率评测。查询拆解与证据选择由评审执行；原始响应见 [heldout-reader-audit.json](heldout-reader-audit.json)。
最终实现已重放全部 23 次原始请求，合计 63,248 字节，6 项任务均在原定预算内。
除加载时间外，全部正文与状态均保持一致。当前源码哈希和逐请求比较见 [reader-replay.json](reader-replay.json)。

| 读者场景 | 实际调用 / 预算 | 响应字节 / 预算 |
|---|---:|---:|
| 科研复现失败经历与审稿改进建议 | 5 / 6 | 10,375 / 30,000 |
| 提示词优化的诊断讨论 | 2 / 5 | 6,808 / 22,000 |
| 数学讨论的跨日期来源 | 4 / 7 | 12,410 / 36,000 |
| 引文工具与相关讨论 | 4 / 7 | 12,772 / 36,000 |
| 视频任务中既有知识的影响 | 3 / 5 | 6,683 / 24,000 |
| 缺刊时寻找实际可读期刊 | 5 / 5 | 14,200 / 20,000 |

6 项均在预算内取得足够回答的公开证据，仍保留以下不足：

- 数学场景的长问题首次返回 0，改为“编程门槛 数学”后找回证据。
- 提示词优化的 3 个候选只有首项直接相关，另外两项是宽泛的 RSI 内容。
- 固定库查询“科研经验”仍将 UniPat benchmark 排第一，强相关研究经历位于第 2、3 名。
- 日报与周报可能重复描述同一经历，回答时需按来源归并。
- 查询早期缺刊日期需要翻阅目录，接口尚未直接返回邻近可读期数。

旧版下载索引或整份资料 JSON 也能完成部分相同意图。新增接口提供更直接的路径，并不意味着旧版完全无法完成任务。
比较应区分接口流程、排序质量和传输量。绘图任务正文减少 84.3%，但加入周报关联后，全库分页响应增加 50.5%。

## 剩余边界

检索仍依靠词法匹配。英文完整问句和中文改写的语义召回尚不稳定；未命中时可保留实体、编号，再用主题词重试。
整期中的 9 段“动向观察”不在话题目录中，仍可从期刊 Markdown 读取。
本轮仅使用本地公开语料，没有测量线上延迟、真实访问行为或部署后的运行情况。

下一轮应先增加长问句、同义改写、无答案与多来源综合题，再比较查询改写或语义排序方案。
现有 16 个固定流程保留作回归检查，不应作为未来方案的唯一评价集。
